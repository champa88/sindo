한자 몬스터 헌트 - 구글로 배포하고 결과 모으기

폴더 구성
- index.html      사이트 본체 (이 파일 하나가 게임 전체예요)
- apps-script.gs  구글 시트로 학생 결과를 모으는 코드 (선택)
- firebase.json   Firebase Hosting(구글 호스팅) 배포용 설정

========================================
1. 구글로 사이트 올리기 (Firebase Hosting)
========================================
구글 드라이브나 구글 사이트 도구는 이 게임 같은 HTML 파일을 직접 실행해 주지 못해요.
구글에서 무료로 웹사이트를 올릴 수 있는 Firebase Hosting을 쓰면 https 주소가 생겨요.

1) console.firebase.google.com 에서 프로젝트를 새로 만들어요. (구글 계정 필요)
2) 컴퓨터에 Node.js를 설치한 뒤, 터미널에서 아래 두 줄을 실행해요.
     npm install -g firebase-tools
     firebase login
3) 이 폴더(hanja-site) 안에서 실행해요.
     firebase use --add        (만든 프로젝트를 선택)
     firebase deploy --only hosting
4) 끝나면 https://프로젝트이름.web.app 주소가 나와요. 이 주소가 학생들에게 줄 사이트 주소예요.

명령어가 어렵다면 앞에서 안내한 Netlify Drop(app.netlify.com/drop)에 폴더를 끌어다 놓는 방법도 돼요.

========================================
2. 학생들에게 나눠 주기
========================================
- 구글 클래스룸: 수업 > 만들기 > 자료(또는 과제) > 링크 추가에 사이트 주소를 넣어요.
  앱의 ⚙ 설정에서 복사한 공유 링크를 넣으면 제목, 시간, 한자 목록이 학생 기기에 함께 적용돼요.
- 구글 사이트: 링크 버튼이나 텍스트 링크로 연결해 주세요.
  페이지 안에 삽입(임베드)하면 위치와 카메라 권한이 막혀서 주변 탐색과 AR이 작동하지 않아요.
- 폰에서 열 때 크롬(안드로이드)이나 사파리(아이폰) 같은 기본 브라우저로 열어요.

========================================
3. 구글 시트로 학생 결과 모으기 (선택)
========================================
학생이 도감 탭에서 결과를 제출하면 선생님의 구글 시트에 이름별로 한 줄씩 정리돼요.

1) 새 구글 시트를 만들어요.
2) 메뉴에서 확장 프로그램 > Apps Script 를 열어요.
3) 기존 코드를 지우고 apps-script.gs 내용을 붙여넣은 뒤 저장해요.
4) 오른쪽 위 배포 > 새 배포 > 유형 선택에서 "웹 앱"을 골라요.
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
5) 배포를 누르고 처음이면 권한을 허용해요. 나오는 웹 앱 URL(…/exec 로 끝나요)을 복사해요.
6) 게임의 ⚙ 설정 > "구글 시트 결과 수집 주소"에 붙여넣고 저장해요.
7) 설정 창의 공유 링크를 학생들에게 보내요. 이 링크에 수집 주소가 담겨 있어요.
8) 학생은 도감 탭에서 이름(또는 번호)을 적고 결과 제출을 누르면 돼요.
   제한 시간 게임이 끝날 때도 이름이 적혀 있으면 자동으로 제출돼요.

주의할 점
- 수집 주소를 아는 사람은 누구나 시트에 결과를 보낼 수 있어요. 학생들에게만 공유해 주세요.
- 학생 이름 대신 번호나 별명을 쓰도록 안내하는 것을 권해요. 개인정보 수집은 학교 지침에 맞게 안내해 주세요.
- 학교 구글 계정(Workspace)은 관리자 설정에 따라 "모든 사용자" 배포가 막혀 있을 수 있어요.
  그럴 때는 학교 정보 담당 선생님께 문의하거나 개인 구글 계정으로 만들어 주세요.
- 전송 결과는 화면에서 성공 여부를 정확히 확인할 수 없어요. 처음 한 번은 시트에 줄이 생겼는지 확인해 보세요.
- Apps Script 코드를 고친 뒤에는 배포 > 배포 관리에서 새 버전으로 다시 배포해야 반영돼요.

========================================
알아 두세요
========================================
- 진행 기록은 학생 각자의 기기에 저장돼요. 결과 수집을 켜지 않으면 어디로도 전송되지 않아요.
- 위성 지도(Esri), 일반 지도(OpenStreetMap), 건물 윤곽 정보는 해당 서비스 서버에서 불러와요.
  접속한 기기의 IP 주소 같은 정보가 그 서버에 전달돼요. 학생·학부모 안내에 참고하세요.
- 지도 오른쪽 아래의 출처 표시는 지우지 마세요.
- 위치, 카메라, 모션 센서는 https 주소에서만 작동해요.
